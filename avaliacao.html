8,0 PONTOS Critérios Principais da Pipeline
1. Ingestão de dados
Simulador gera dados de GPS (300 ônibus, 20 linhas), catracas (18 estações VLT) e bikes em JSON imutável com timestamp UTC. Detecta outliers (velocidade > 100 km/h → quarentena).
→ pipeline_simples.py ingestao() data/bronze/gps/*.json data/bronze/catracas/*.json
máx 1,6 pts
2. Armazenamento — Data Lake Medallion
Bronze (JSON raw) → Silver (Parquet Snappy, schema validado) → Gold (DuckDB, tabelas analíticas). Estrutura padronizada. DuckDB como engine único — sem Docker.
→ pipeline_simples.py data/bronze/ data/silver/*.parquet data/gold/urbanflow.duckdb
máx 1,6 pts
3. Transformação — Bronze → Silver → Gold
bronze_to_silver(): SQL via DuckDB — valida schema, remove outliers, grava Parquet Snappy.
silver_to_gold(): Cria kpi_operacional (velocidade média, OTP, semáforo) e agg_demanda (entradas, saídas, receita).
→ pipeline_simples.py bronze_to_silver() silver_to_gold()
máx 1,6 pts
4. Orquestração
main(): orquestra todas as etapas em sequência com tratamento de erros e log de tempo.
urbanflow_pipeline.py: DAG Airflow completo para ambiente produtivo (schedule diário).
→ pipeline_simples.py → DAG Airflow main()
máx 1,6 pts
5. Consumo / Serving
serving(): queries SQL diretas no Gold com KPIs impressos no terminal.
gerar_dashboard(): lê DuckDB Gold e gera dashboard com 4 gráficos Chart.js hospedado no GitHub Pages.
→ Ver Dashboard ao Vivo → pipeline_simples.py serving() gerar_dashboard()
máx 1,6 pts
